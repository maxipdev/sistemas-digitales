# Ejercicio 4 — Negativo

Completar `negativo_4b.sv`: recibe `dato` de 4 bits y devuelve `negativo`.
No utiliza un sumador.

Ejecutar `make sim` y verificar que los 16 casos pasen. No modificar
el testbench. En HDL Studio usar `negativo_4b` como top y agregar todos
los `.sv` locales salvo el testbench. Ver `../../README.md`.
